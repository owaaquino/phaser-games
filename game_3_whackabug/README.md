# Whack A Bug - A mouse point and click game

Experimenting click events in [Phaser](https://github.com/phaserjs/phaser)!

This is the official code repository for my [Building Games with Phaser](https://owaaquino.com/tags/game-development) blog series.

## Demo

You can play this game live [here](https://owaaquino.itch.io/whack-a-bug) in [itch.io](https://itch.io/)

## How to play

This is a point and click game, so you'll need a mouse.
