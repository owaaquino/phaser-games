# Fantasy Man - Adventure Platformer game

My second game built with [Phaser](https://github.com/phaserjs/phaser)!

This is the official code repository for my [Building Games with Phaser](https://owaaquino.com/tags/game-development) blog series.

## Demo

You can play this game live [here](https://owaaquino.itch.io/fantasy-man) in [itch.io](https://itch.io/)

## How to play

| Keys                  | Description                    |
| --------------------- | ------------------------------ |
| Left and Right arrows | Moves the Player left or right |
| Space bar             | Player jumps                   |
| Up and Down arrows    | Navigate the menu              |
| Enter                 | Select item in menu            |
